# Security Policy

## Scope

This repository is a public GitHub Actions template for recording a small daily continuity log.

## Do not commit

Never commit passwords, access tokens, API keys, cookies, private research data, local file paths, or real personal email addresses.

Use the GitHub noreply address associated with your account in the GIT_AUTHOR_EMAIL repository variable.

## Reporting a problem

If you find a security issue, do not publish credentials or exploit details in a public issue. Contact the maintainer privately through the contact method shown on the GitHub profile.

## Important limitation

This template records automated continuity activity. It is not evidence of substantive software development and should not be used to misrepresent work.
